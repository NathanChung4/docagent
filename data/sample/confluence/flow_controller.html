Flow Controller

Overview

The flow controller regulates the rate at which work units pass through the upstream pipeline. It exposes three tunable parameters and emits two telemetry metrics per work unit. Owners should validate the flow controller before any release that touches the pipeline scheduler.

Parameters

  • rate_limit (int, 1–1000, default 100) — maximum work units per second.
  • burst_size (int, 1–500, default 50) — number of units allowed above the steady-state rate during a short burst.
  • backoff_ms (int, 0–5000, default 250) — pause inserted after each burst before the steady rate resumes.

Validation Procedure

  1. Stage a synthetic workload of 10,000 work units.
  2. Sweep rate_limit across {50, 100, 200, 500} with the other two parameters at default.
  3. Confirm steady-state throughput stays within 5% of the configured rate_limit.
  4. Confirm latency p99 stays under 100ms at the default settings.

Known Issues

When burst_size exceeds rate_limit, the controller can briefly double-count units during the burst-to-steady transition. Until this is fixed in the next release, set burst_size ≤ rate_limit for production runs.

Related Components

Pairs naturally with the signal buffer downstream and the clock divider upstream.
