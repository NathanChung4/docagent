Pressure Sensor

Overview

The pressure sensor reports the load on the input queue once per sampling interval. Downstream schedulers use its readings to apply backpressure when the queue depth grows beyond safe limits.

Parameters

  • sample_interval_ms (int, 10–10000, default 100) — how often the sensor reads queue depth.
  • warn_threshold (int, 0–100, default 70) — percent fill at which a warning event is emitted.
  • crit_threshold (int, 0–100, default 90) — percent fill at which the sensor signals critical pressure and asks upstream to throttle.

Validation Procedure

  1. Drive the input queue from 0% to 100% fill in 10% steps.
  2. Confirm a warn event fires at 70% and a crit event at 90%, with no false positives below those thresholds.
  3. Sweep sample_interval_ms across {50, 100, 250, 500} and confirm event latency scales linearly.

Known Issues

If warn_threshold ≥ crit_threshold, the sensor refuses to start and logs a configuration error. This is intentional — do not work around it by clamping in user code.
